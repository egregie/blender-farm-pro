# 06_archive/ — This fork's own archive

**Status: empty at fork creation — intentionally, not copied from PharmaGen PRO.**

PharmaGen PRO's own legacy/archive material (`trash/`, ~2600 files: dead
renderers, superseded pipelines, historical logs) was **deliberately not
copied here**. This fork's stated goal is to be "clean, well-organized" — 2600
files of unrelated legacy weight would contradict that on day one. That
material remains in the original `pharma_v2` repository if ever needed.

This folder exists so **this fork's own future** superseded/legacy material
(old Blender scene attempts, deprecated scripts, etc.) has a designated home
from the start, mirroring PharmaGen PRO's `trash/` convention (archive, never
auto-restore, never silently delete).
