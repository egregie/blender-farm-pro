## Functional Requirements

1. README после правки описывает то, что действительно делается.
2. Порог качества выведен из эталонов и обоснован числами.
3. Каждый кандидат сверяется оптически, а не по названию товара.
4. На шаблон сохраняется не более 7 изображений.
5. Исполнение останавливается перед паспортами и ждёт отбора владельцем.
6. Паспорт строится только по отобранным и содержит 12 секций A–L в формате существующих.
7. Каждое утверждение помечено `[Observed]` / `[Measured]` / `[Estimated]` / `[Unknown]`;
   для `[Estimated]` указана уверенность.

## Workflow Requirements

### Критерий отбора

Единственный приоритет — **читаемость дизайна передней грани**. Ракурс, задняя панель,
блистеры, вскрытая упаковка, варианты дозировки **требованиями не являются**. Изображение
годится, если по нему измеримо то, что требуют секции B, F, G, H: границы текстовых блоков,
сетка, типографика, цветовые зоны передней грани.

### Оптическая сверка

Сравнение с тремя эталонами по измеримым признакам: доля передней грани в кадре; резкость
грани (метод выбирает исполнитель и фиксирует); различимость текстовых блоков в масштабе,
достаточном для измерения bounding box; отсутствие перекрытий грани рукой, ценником, бликом.
Порог по каждому признаку выводится из эталонов на шаге 3 и записывается числом. Кандидат,
уступающий худшему эталону по любому признаку, отклоняется.

### Политика источников

Сохраняется белый список README: сайты производителей, регуляторные базы (FDA/DailyMed, EMA,
MHRA), лицензированные аптеки, официальные дистрибьюторы, базы вкладышей. Расширять
запрещено. Для каждого файла записывается URL и дата загрузки.

### Failure handling

| Ситуация | Действие |
|---|---|
| Ни один кандидат не прошёл | Папка пуста, шаблон помечен `insufficient_references` с перечнем проверенных источников. Понижать порог запрещено. |
| Ровно один годный | Сохранить, пометить `single_source` — это ограничение реконструкции, не успех. |
| Два неразличимы по качеству | Сохранить оба, в пределах лимита. |
| Достигнут лимит 7 | Поиск прекращается, записать, что усечён. |
| Сетевой запрос не удался | Один повтор, затем записать источник недоступным. Не подставлять изображение другого шаблона. |
| Файл битый | Удалить, записать, не засчитывать в лимит. |

### Наблюдаемость

Единственный журнал — `03_knowledge_graph/reference_benchmarks_ssot/collected_references_log.md`.
На каждый сохранённый файл: шаблон, имя, URL, дата, разрешение, результат сверки по каждому
признаку. На каждый отклонённый: URL и причина. **Молчаливое отбрасывание запрещено.**

### Человеческие гейты

1. **После сбора** — владелец отбирает изображения. Паспорта не строятся до подтверждения.
2. **После паспортов** — подтверждение до любого использования ниже по конвейеру.

## Invariants

Нарушение любого — остановка и вопрос, не обход.

1. **Три эталона не изменяются и не перезаписываются.** Разрешено только удалить
   подтверждённые дубликаты в Kamagra и добавить туда недостающие паспорт и метаданные.
2. **Порог выводится из эталонов, а не назначается.** Если эталон не проходит собственный
   порог — это находка о пороге, а не повод исключить эталон.
3. **Никаких изображений вне белого списка источников.**
4. **Лимит 7 не превышается ни при каких условиях.**
5. **Паспорт строится только по отобранным владельцем изображениям.**
6. **Ни одно утверждение не остаётся без метки наблюдения.** Невидимое — `[Unknown]` и
   секция L, а не догадка.
7. **Формат задают два существующих паспорта**, а не README, если они расходятся.
8. **Ничто в `src/`, `05_assets/`, `schemas/`, `04_passports/`, `tests/` не изменяется.**

## Implementation Steps

### Фаза 1 — привести эталоны в порядок

1. **Discovery.** Выполнить Discovery Phase, зафиксировать рабочую очередь.
2. **Дедупликация Kamagra.** Подтвердить идентичность пар по хешу пикселей. Удалить
   дубликаты, записать что и на каком основании.
3. **Порог качества.** Измерить все изображения эталонов: разрешение, резкость грани, долю
   грани в кадре. Вывести минимумы. Отдельно решить судьбу файла 608×380 — либо он эталон и
   минимум опускается, либо выбывает; выбрать одно, обосновать числами.
4. **Паспорт Kamagra.** Построить паспорт и `metadata.json` в формате существующих.
5. **Kamagra в SSOT.** Добавить третьим объектом, не трогая Viagra и Cialis.

### Фаза 2 — заточить инструкцию

6. **Правка README.** Фактический путь к эталонам; выведенный порог; критерий читаемости
   передней грани вместо обязательных ракурсов; лимит 7; правило «при сомнении оба»; два
   гейта. Ракурсы остаются желательными, а не требованием.
7. **Сверка README с диском.** Пройти сверху вниз, каждое утверждение о путях, файлах и
   форматах проверить. Расхождение исправить или записать находкой.

### Фаза 3 — сбор

8. **Пилот на одном шаблоне.** Пройти полный цикл, остановиться, показать владельцу:
   сработали ли пороги, не отклоняется ли всё, не проходит ли мусор. **Не запускать
   остальные 28 без подтверждения.**
9. **Остальные шаблоны.** Последовательно, с журналированием, без превышения лимита.
10. **Отчёт по сбору.** Сколько закрыто, сколько `insufficient_references`, сколько
    `single_source`, где поиск усечён лимитом.

### Фаза 4 — паспорта, после отбора

11. **Ожидание отбора.** Остановиться. Не начинать шаг 12 без явного указания.
12. **Паспорта.** По отобранным, в формате существующих, с метками наблюдения.
13. **Проверка.** 12 секций на месте, нет утверждений без метки, `metadata.json` согласован,
    координаты в `[0.0, 1.0]`.

## Edge Cases

1. **Эталон не проходит собственный порог** — уже известно: 608×380 против минимума 800.
   Решается на шаге 3 явным выбором.
2. **Товара нет в открытых источниках** — `insufficient_references`, не подменять похожим
   товаром другого производителя.
3. **Другая дозировка или число таблеток** — годится, если грань читается; паспорт описывает
   геометрию и дизайн. Отметить в секции L.
4. **Водяной знак** — отклонять по правилу >20% поверхности, измеряя, а не оценивая.
5. **Одинаковый кадр на разных сайтах** — дедуплицировать по хешу пикселей, не по URL.
6. **Папка непуста, но комплект неполон** — обрабатывать как пустую в части недостающего,
   ничего не перезаписывая.
7. **Разрешение достаточно, но грань мала в кадре** — отклонять: измеримость важнее пикселей.
8. **Список папок не совпадает с `catalogue_sweep.py`** — работать по папкам, расхождение
   записать находкой.
