# 00_governance/ — Decisions, audits, release engineering

Forked from PharmaGen PRO's equivalent documentation (`docs/DECISIONS/`,
`docs/audits/`, `docs/release/`) — architecture decision records, the
production-readiness/bus-factor/CRM-readiness audits, and the release
engineering set (technical debt, risk register, roadmap, scorecard,
certification). Copied here for context on *why* the source project looks the
way it does. A duplicate copy used to sit under `docs/` as well; it was
removed on 2026-08-02 once this fork started editing the governance copies,
so these files are now the only ones.

| Subfolder | Contents |
|---|---|
| `DECISIONS/` | ADR-001..006 — why Gemini, why Markdown, why WEBP, why RPA, why SSOT-as-routing-authority, why the unified `main.py`. |
| `audits/` | Bus Factor, Production Readiness, CRM Readiness audits. |
| `release/` | Technical debt register, risk register, roadmap, architecture health, dependency lifecycle, repository scorecard, release certification. |

This fork's **own** governance decisions (e.g. an eventual "why Blender" ADR)
should be added here going forward.
