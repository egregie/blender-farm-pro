# Repository Audit & Classification

> Produced during the "Final Repository Polish & Production Packaging" phase.
> Nothing was deleted — superseded artifacts were archived into `trash/` via
> `git mv` (history preserved). Production data and import surfaces were kept in
> place to protect the runtime Pipeline.

## Classification key

| Category | Meaning |
|---|---|
| `keep-root` | Project-level file that legitimately belongs in the root. |
| `runtime` | Imported/executed by the Pipeline — must stay where the code expects it. |
| `runtime-data` | Production data / state — never archived or moved. |
| `→ scripts/` | Auxiliary or maintenance tool, not part of the 3 Stages. |
| `→ trash/` | Obsolete / legacy / duplicate / generated snapshot — archived. |
