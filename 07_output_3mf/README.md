# 07_output_3mf/ — Reserved (currently unused)

**Status: empty by design, not an oversight.**

3MF is a 3D-printable mesh/manufacturing format. Nothing in this fork currently
produces 3D-printable geometry — the Blender work here targets **photorealistic
2D packshot renders** (PNG output), not exportable 3D print files. Placing the
existing raster reference images here would have been mislabeling, so they live
in `01_input_raster/` instead (see `01_input_raster/reference_analysis.md`).

**Possible future use:** if Blender Farm Pro ever needs literal exportable 3D
packaging meshes (e.g. for a physical prototype or a die-line tool), this is
where they'd go.

If this folder's intended purpose was different (e.g. shown in a screenshot not
available when this fork was created), redirect it — see
`00_PROJECT_STATE/CURRENT_STATE.md` §Assumptions.
